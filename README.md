# 智能养牛 · P10-A 原型

面向肉牛育肥小户/合作社的软硬一体智能养殖方案。目标是**至少 15 天无人现场参与**的自动投喂与饮水，支持远程监控、远程复位与远程操作。

当前阶段：**P10-A 10 头原型车 + ESP32-S3 控制器**，用于验证可行性并压缩试制成本；产品形态面向 100–300 头规模。

## 方案基线

| 项 | 结论 |
|---|---|
| 饲料 | 玉米秸秆切至 **5 cm**，干物质 ≥70%（水分 ≤30%） |
| 投喂量 | 粗料 4–5 kg/头·日，精料 5–6 kg/头·日 |
| 投料车 | **无轨、远程控制**（后期 AI 视觉），2×400 W 行走，48 V 30 Ah |
| 料仓 | 粗料 250 kg + 精料 150–180 kg，同车分区，**先粗后精** |
| 卸料 | 后部全宽门（780×180）+ 门下皮带（400×1555，33° 爬坡） |
| 通道 | 饲喂通道净宽约 2 m；装料站位置可调 |
| 供电 | 电池 + 单充电桩 |
| 控制器 | ESP32-S3-WROOM-1-N16R8 + 自研 4 层载板（300×180 mm） |
| 预算 | ≤ 20 万元（当前 BOM 约 3.2 万元/台原型） |

### PCB 说明

- 工程：`P10-A 控制器载板`（嘉立创 EDA），原理图 `P10A-Ctrl`，PCB `P10A-PCB`。
- 设计脚本在 `work/eda/`：布局 `place_single300v4.js`、电源/信号布线 `route1_power.js` / `route2_signals.js`、GND 铺铜 `route8_gnd_clean.js`。
- 关闭“保留孤岛”后仍有 13 个 GND 焊盘需要手工补缝合过孔（坐标清单见 `docs/11-P10-A-控制器设计.md` 第 8 节）；补完后 DRC 可清零。
