# 自走式电动 TMR 撒料车：选型、数字化终端与实施方案（v0.1）

> ⚠️ **本方案已不满足 2026-11-10 新增的"15 天无人参与"要求。**
> 自走式 TMR 每日需人工取青贮、驾驶撒料、充电，无法做到 15 天无人。
> 保留本文件作对比与过渡参考；重构方案见《03-15天无人值守方案重构》。

> 日期：2026-11-10
> 前提：现场仅 220V 单相；50 头肉牛育肥；先单场验证，再合作社复制
> 关联：《01-需求基线与可行性推演 v0.4》

---

## 一、结论先行

1. **整机路线**：3 m³ 自走式电动 TMR 撒料车，220V 充电，免 380V、免固定机房。
2. **自研定位**：首版不做整机主控，做**品牌无关的数字化终端 + SaaS**——装在任意品牌 TMR 上，采集称重与运行数据、引导配方、上云、小程序。整机主控留到二期多机联动时再评估。
3. **验证方式**：自家 50 头跑通配方与设备，同时以闲置产能服务 2–3 户邻居，顺带验证共享服务的收费模型。
4. **必须提前接受的现实**：这台设备在 50 头单场经济性偏弱（见第五节），验证期的核心产出是**料肉比数据与共享服务可行性**，不是短期回本。

## 二、整机选型要求

| 参数 | 建议要求 | 理由 |
|---|---|---|
| 料箱容积 | 3 m³（有效 ≥2.4 m³） | 50 头日粮约 1.1–1.25 t，1–1.5 批/日 |
| 搅拌形式 | 立式搅龙 1–2 个 | 青贮 + 秸秆混合均匀性优于卧式 |
| 搅拌电机 | ≥4 kW | 青贮与秸秆负载 |
| 行走 | 四轮电动，≥3 kW | 牛舍通道与缓坡 |
| 出料 | 侧置输送带或绞龙，宽度可调 | 沿料槽均匀撒料 |
| 称重 | 4 点，误差 ≤1%，仪表带 RS485 | 配方计量与数据采集的前提 |
| 电池 | 锂电 60V / ≥120Ah（≥7 kWh） | 冬季衰减、循环寿命优于铅酸 |
| 续航 | 综合作业 ≥4 h | 每日 2 批 |
| 充电 | 220V，3–5 kW，≤8 h | 夜间充电，需独立回路 |
| 上料高度 | ≤1.5 m，可选配提升机 | 降低人工上料强度 |
| 最小通道 | ≤1.8 m | 散栏牛舍通道 |
| 防护 | IP54，防雨防尘 | 牛舍氨气、冲洗环境 |
| **数据接口** | **RS485/Modbus 或 CAN** | **决定自研终端能否低成本接入** |
| 价格 | 5–8 万 | 预算区间 |

**选型优先级：数据接口 > 电池与续航 > 搅拌均匀性 > 价格。** 没有开放接口的整机，后续要么加装传感器，要么只能人工录入，数字化价值大打折扣。

## 三、供应商评估清单

- 是否有 3 m³ 电动自走式成熟机型，至少 3 个 50–100 头场的实际案例；
- 电池品牌、质保年限（锂电建议 ≥3 年或 2000 循环）；
- 称重仪表型号与协议是否开放（要型号、要协议文档）；
- 售后网点距离、响应时间、常用配件（搅龙、输送带、电池）供应；
- 是否支持出料方向、撒料宽度定制；
- 交期与是否可试机；
- 能否提供作业视频与现有客户联系方式。

## 四、数字化终端方案

### 4.1 产品定位

**不做整机主控，做后装终端。** 原因：

- 整机 OEM 已含电机控制、称重、液压/输送控制，替换主控风险高、保修失效；
- 后装终端可跨品牌复用，不绑定单一供应商；
- 软件与数据是长期壁垒，硬件只是入口。

### 4.2 硬件构成

| 部件 | 建议 | 成本 |
|---|---|---|
| 主控屏 | 10 寸安卓工业屏（RK3568，2G+16G），RS485×2，4G | 800–1,500 元 |
| 通信 | 4G Cat.1 模块（可内置） | 100–200 元 |
| IO | DI/DO 各 4 路，隔离 | 100–200 元 |
| 电源 | 12/24V 宽压，隔离，防反接 | 100–200 元 |
| 安装 | 防振支架、IP54 防护 | 100–200 元 |
| **合计** | | **1,200–2,300 元** |

### 4.3 软件 MVP

**终端本地：**
- 配方引导：按原料逐项显示目标重量，实时累计，达标提示；
- 批次记录：时间、配方、各原料实际量、搅拌时长、出料量、操作人；
- 断网缓存：本地保存，恢复后补传；
- 报警：称重异常、电机过载、电量低、未按配方、超时。

**云端：**
- 设备管理、配方库、批次台账、报警中心、OTA；
- 多场/多户管理（见 4.4）。

**小程序：**
- 配方下发、批次查看、报警推送、日报；
- 首屏只显示“今天正常/异常 + 已配料批次”，不做复杂图表。

### 4.4 数据模型（首版即多场就绪）

```
coop(id, name)
farm(id, coop_id, name, owner, phone)
device(id, farm_id, model, sn, fw)
material(id, name, unit)
ration(id, farm_id, stage, name, version)
ration_item(id, ration_id, material_id, target_kg, tolerance)
batch(id, device_id, ration_id, operator, start_ts, end_ts, status)
batch_item(id, batch_id, material_id, target_kg, actual_kg)
alarm(id, device_id, type, level, ts, resolved_ts)
user(id, farm_id, role)
```

首版只有 1 个 farm，但表结构、权限、接口都按多 farm 设计。否则合作社复制时要重写。

### 4.5 接口策略（OEM 不开放时）

1. 首选：整机控制器开放 RS485/Modbus；
2. 次选：直接读称重仪表（多数仪表带 RS485）；
3. 电机状态：加装电流互感器或取辅助触点；
4. 位置/里程：GPS 或霍尔传感器；
5. 兜底：终端人工确认批次，软件仍可用，但自动化程度降级。

## 五、BOM 与 TCO

### 5.1 一次性投入

| 项目 | 金额（元） | 备注 |
|---|---|---|
| 自走式电动 TMR 3 m³ | 50,000–80,000 | 含充电器 |
| 上料提升机（选配） | 5,000–10,000 | 降低人工上料强度 |
| 充电回路/配电改造 | 2,000–5,000 | 4 mm² 线、25 A 空开、接地 |
| 自研终端 | 1,200–2,300 | |
| 雨棚/地面硬化 | 3,000–8,000 | 视现场 |
| 安装调试/培训 | 3,000–5,000 | |
| **合计** | **6.4–11 万** | 不含青贮取料机 |

### 5.2 年成本

| 项目 | 金额（万元/年） |
|---|---|
| 折旧（5 年） | 1.3–2.2 |
| 电池摊销（3–5 年更换） | 0.2–0.5 |
| 电费（含充电损耗） | 0.15–0.25 |
| 维护/配件 | 0.3–0.5 |
| **合计** | **1.95–3.45** |

### 5.3 收益（自家 50 头）

| 项目 | 金额（万元/年） |
|---|---|
| 料肉比改善 3–5% | 1.2–2.4 |
| 浪费下降 2–3% | 0.8–1.4 |
| 人工节省 | 0（甚至为负） |
| **净收益** | **-1.45 ~ +1.85** |

**单场自用经济性偏弱，这是必须正视的。** 修复路径见 5.4。

### 5.4 验证期叠加邻居服务

利用 3 m³ 机器的闲置产能，服务 2–3 户邻居（100–150 头）：

| 项目 | 估算 |
|---|---|
| 年加工量 | 800–1,200 t |
| 加工费 | 30–50 元/t |
| 服务收入 | 2.4–6 万/年 |
| 增量人工 | 1–2 万/年 |
| 增量能耗/维护 | 0.3–0.5 万/年 |
| **服务净收入** | **1.1–3.5 万/年** |

叠加后整体净收益约 -0.3 ~ +5.3 万/年，**区间很宽，必须实测**。这也是验证期最重要的商业实验。

## 七、现场勘测清单

**供电**
- 户内 220V 总容量、现有负荷；
- 充电位是否可单独敷设 4 mm² 回路与 25 A 空开；
- 接地电阻、漏电保护；
- 充电位防雨、冬季保温条件。

**通道与牛舍**
- 撒料车通行宽度（≥1.8 m）、转弯半径、坡度、门槛；
- 地面承载（整机 1.5–2 t）；
- 料槽长度、高度、分组方式、撒料高度。

**上料**
- 青贮窖与牛舍距离、取料方式、运输路径；
- 上料区硬化、雨棚、上料口高度；
- 精料与秸秆的存放位置。

**其他**
- 排水与清洗条件；
- 4G 信号强度；
- 牛群头数、体重、育肥阶段、分组；
- 邻居距离、意愿、头数（为共享服务做准备）。

## 八、验证指标

| 指标 | 目标 |
|---|---|
| 配料精度 | 各原料 ±2% |
| 混合均匀度 | CV ≤10% |
| 撒料均匀度 | 槽内剩料差异 <15% |
| 日增重 / 料肉比 | 与人工组对照，**经济性成立的前提** |
| 人工耗时 | 逐环节记录（取料/上料/搅拌/撒料/清洗） |

| 故障 | 次数、类型、恢复时间 |
| 牛只 | 采食、应激、换料过渡 |
| 共享服务 | 邻居意愿、收费接受度、实际加工量 |

## 九、风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| 电池冬季衰减 | 高 | 室内/保温充电，预留续航余量，记录低温数据 |
| 220V 容量不足 | 高 | 勘测时核算总容量，必要时错峰充电 |
| 通道/转弯不满足 | 高 | 售前勘测，不满足不采购 |
| 上料人工强度大 | 中 | 配提升机，优化上料口高度 |
| OEM 数据接口不开放 | 中 | 优先选开放机型，备选读仪表/加传感器 |
| 单场经济性不足 | 高 | 邻居服务 + 合作社复制 + 补贴 |
| 混合均匀度不达标 | 中 | 按物料与装载量试机验证 |
| 青贮品质波动 | 中 | 收购标准、定期检测含水率 |
| 售后与配件 | 中 | 选网点近的供应商，常备易损件 |

## 十、向合作社复制的准备

首版就要为复制留好接口，避免二次开发：

1. **数据模型**：coop / farm / device 三级，已就绪；
2. **分户配方与结算**：按户下发配方、按批次计量、按月出账；
3. **设备利用率**：服务半径、日加工量、闲置率；
4. **服务定价**：元/吨 或 元/头·日，验证期实测农户接受度；
5. **运维 SOP**：充电、清洗、易损件更换、故障分级；
6. **培训体系**：饲养员 30 分钟上手，老板看日报。
