# 11 · P10-A 控制器设计

> 适用：P10-A 原型（10 头、48V 30Ah、2×400W 行走、0.37/0.37/0.18 kW 作业、全宽门 2 推杆、6 路称重）。
> 基线：**ESP32-S3-WROOM-1-N16R8 + 自研载板**；安全链硬线；4G 路由 + 3 路 IP 相机；PLC 为备选（见第九节）。
> 相关：`10-P10-A-选型与装配.md`、`P10-A-BOM-选型.csv`。

## 一、设计目标与边界

| 项 | 要求 |
|---|---|
| 供电 | 48V 15S LiFePO4（54.6V 满电，40A BMS） |
| 控制 | 远程驾驶、10 站自动投喂、先粗后精、称重闭环 |
| 安全 | 急停/防撞/倾角/失联/过流 → 停车抱闸；安全功能不经 MCU |
| 环境 | -10～45℃，IP65 电控箱，牛舍氨气/粉尘/振动 |
| 无人 | 本地计划 + RTC；断网 2 s 停车；看门狗；OTA 回滚 |
| 成本 | 控制器套件 ≤2,200 元（含 4G 路由/存储） |

## 二、三层架构

```
[安全层]  急停×2 / 防撞×2 / 倾角开关 ──→ 安全继电器 ──→ 主接触器 + 抱闸
                                              ↑
[实时层]  ESP32-S3 载板：DI/DO / RS485×2 / ADS1256 / I2C / SD / RTC
              │        │          │            │
              │        │          │            └─ 6 路称重、门限位、倾角
              │        │          └─ 5 台驱动器（Modbus RTU）
              │        └─ 全宽门 H 桥、链板/侧带/绞龙使能、警示灯
              └─ Wi-Fi → 4G 路由 → 云/手机；HMI 串口
[连接层]  4G 路由 USR-G806s：3 路 IP 相机 RTSP、MQTT/TLS、OTA
```

**原则：** 安全链不经过 MCU；MCU 只做“运行使能”和“监督”；即使 MCU 死机，外部看门狗也会断开运行使能、抱闸。

## 三、电源与配电

| 支路 | 电压 | 容量 | 负载 |
|---|---|---|---|
| 主回路 | 48V | 100A 接触器 / 125A ANL | 5 台驱动器 |
| 作业 | 48V | 5×10A 分支保险 | 链板/侧带/绞龙/2 行走 |
| 控制 | 24V | 10A（240W DC/DC） | 安全继电器、接触器线圈、门推杆、抱闸、警示灯 |
| 通信 | 12V | 5A（60W DC/DC） | 4G 路由、3 相机、HMI、交换机 |
| 逻辑 | 5V/3.3V | 15W | ESP32 载板、ADS1256、传感器 |

- 预充 50Ω/50W；主接触器 24V 线圈（ZJW-100A/24V 或 48V 线圈经 48V 继电器）。
- 充电：4 芯（48V+/48V-/PE/联锁）；充电时主接触器断开，联锁信号进 MCU，**行走禁止**；BMS 负责过充/过温。
- 急停/防撞断电：安全继电器 → 主接触器 + 抱闸；抱闸**统一 24V 失电制动**（已确认，与安全链同电压）。

## 六、安全链与联锁

```
急停1 ─┐
急停2 ─┤
防撞1 ─┼─→ 安全继电器(PNOZ s4/国产) ─→ 运行使能继电器 ─→ 看门狗继电器 ─→ 主接触器 + 抱闸
防撞2 ─┤                                      ↑
倾角开关┘                                   MCU 监督
```

- 急停/防撞：常闭双通道进安全继电器；复位必须**现场手动**，远程只能复位非安全故障。
- 倾角：WT901 >8° → MCU 停机；安全链可串机械倾角开关（常闭）做硬保护。
- 失联：>2 s → 零速/停车；>30 s → 告警；恢复后需确认。
- 过流：驱动器硬件保护 + 报警 DI；MCU 停止该动作。
- 看门狗：MCU 死机 → TPL5010 超时 → 运行使能释放 → 接触器断开/抱闸。
- 门：2 推杆**并联 + 十字轴/扭力管机械同步**（优于电子同步）；H 桥 10A + 电流检测；上限/下限 + 时间窗；堵转 >2 s 停止。
- 充电：4 芯联锁 → 行走禁止；主接触器断开；BMS 管理充电。

**安全等级说明：** 急停/防撞/接触器/抱闸按 PL d 目标选件；防撞条若用普通微动开关，只算“停车触发”，不计安全等级；量产建议认证安全触边。

## 七、固件架构（ESP-IDF / FreeRTOS）

| 任务 | 周期 | 职责 |
|---|---|---|
| safety_task | 10 ms | 读安全继电器/急停/防撞/倾角；喂狗；失联计时；故障锁存 |
| motion_task | 20 ms | 行走速度/转向斜坡；驱动器 RS485；限速 0.5 m/s；里程/姿态 |
| feed_task | 50 ms | 门/链板/侧带/绞龙时序；失重计量；清料；10 站状态机 |
| weigh_task | 100 ms | ADS1256 采样/滤波/校零/偏载；箱/仓重量 |
| comm_task | 100 ms | MQTT 遥测/命令/OTA；HMI 串口；日志 |
| log_task | 1 s | SD 环形日志、故障快照 |

**状态机：** INIT → IDLE → MANUAL / AUTO_TRAVEL → AUTO_FEED → RETURN → CHARGE；任意态 → FAULT/ESTOP。

**投料闭环：** 目标粗 2.2 kg/精 2.7 kg；先开侧带 0.5 s → 开门 30–80 → 链板慢速 → 失重到量 → 链停 → 门关 → 侧带清 2–3 s；超调补偿按上次偏差修正；连续 3 次偏差 >8% 报警。

**称重：** 6 路和值；三点调平；0/25/50/75/100% 标定；温度漂移/零点跟踪；空仓校零；偏载 >2% 提示。

**远程：** MQTT over TLS，QoS1；主题 `p10/<id>/telemetry`、`/cmd`、`/ota`；JSON；Last Will；命令：驾驶、急停（软停）、到站、开始/暂停投料、复位、OTA。视频走路由 RTSP，不进 MCU。

**OTA/安全：** 双分区回滚；签名镜像；Secure Boot/Flash 加密；设备证书；日志脱敏。

- 孤岛自动关闭尝试：关闭“保留孤岛”并重建后，仅剩 10 个 GND 对象（U37.2/3/5、U33.10/17、U4.2、C80.2、C81.2 及 2 个缝合过孔）断开。这些焊盘周围是路由器密集扇出区，补过孔/短线会与相邻 VIA、VREF/AIN 焊盘冲突；多次尝试后回退为“保留孤岛”，以保证所有焊盘电气连通。
- 结论：孤岛需在 EDA 交互式处理——关闭“保留孤岛”后对这 10 处补缝合过孔（必要时微调相邻扇出过孔），比自动处理更可靠。

**结构与外设影响**

- 电控箱原 300×220×120 **装不下 300×180 板**（长度无余量），建议改为 **350×250×120** 或 360×260×140。
- 板面积增大后 4G/相机线束、安装孔位置需按新箱体调整；其余电气接口不变。

**收尾建议**

1. 出 Gerber（4 层 + 钻孔 + 坐标）、BOM、贴片坐标；复核 24V/5V 载流与保险。
2. EDA 内处理 GND 孤岛与 6 条轻微间距提示。
3. 若后续要压缩成本/体积，可按 250×140 试一版；300×180 是当前可制造且全部布通的版本。

## 九、PLC 备选

若 ESP32 路线未通过 2 周/14 项故障注入，切小 PLC：
- 信捷 XD5-24T-E（24DI/16DO，RS485×2，支持 Modbus）；
- 安全继电器/接触器/抱闸不变；
- 称重改 **RS485 称重变送器**（如耀华/柯力），或保留 ADS1256 + MCU 做从站；
- 4G 网关独立；IO 表与线束不变，控制箱布局调整。

## 十二、开放问题

**已确认（2026-11-17）：**
1. 5 台驱动器统一 **RS485 Modbus RTU**，UART2，115200，地址 1–5。
2. 抱闸统一 **24V 失电制动**，与安全链同电压。
3. 串口分配：UART0 服务 / UART1 HMI / UART2 RS485 驱动器；BMS 与充电机走 **SC16IS752 UART-A/B**。
4. 电控箱 300×220×120 与车架前部空间**不干涉**。

**待确认：**
5. 4G 路由/相机供电：12V 5A 是否够（3 相机+路由+交换机）；实测。
6. 门同步：2 推杆并联 + 十字轴是否够；若门板刚度不足，改单推杆+扭力管。
7. 称重：ADS1256 与 6 路长线（>2 m）抗干扰；必要时改 RS485 称重变送器。
8. ESP32 路线决策门：2 周连续 + 14 项故障注入 + EMC 预扫。
