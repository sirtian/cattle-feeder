# 15 天无人值守饲喂方案重构（v0.3）

> 日期：2026-11-10
> 触发：全自动定义为"至少 15 天无人参与"
> 结论：现有自走式 TMR 方案不满足，需重构为"干料全自动线"
> 已确认（v0.3）：去青贮、颗粒化全价日粮；范围 = 饲喂 + 自动饮水；50 头验证、产品按 100–300 头设计；允许远程监控与远程复位（"无人"指无现场人工）
> 详细实施包见《04-V1详细设计与15天验证包》

---

## 一、现有 TMR 方案为何不成立

| 每日必需的人工环节 | 自走式 TMR 现状 | 15 天无人要求 |
|---|---|---|
| 青贮取料、装入搅拌机 | 人工 0.5–1 h | ❌ |
| 驾驶撒料车沿槽投喂 | 人工 0.5–1 h | ❌ |
| 充电（插拔、看护） | 人工 | ❌（除非自动充电桩） |
| 清洗搅拌箱/输送带 | 人工 0.2–0.3 h | ❌ |
| 堵料、液压、电池异常处理 | 人工 | ❌ |

**只要一天有一个环节需要人，15 天无人就不成立。** 自走式 TMR 至少有 3 个每日人工环节，无法通过"加大电池、加个 APP"解决。

---

## 二、核心矛盾：青贮 vs 15 天

青贮含水 65–75%，必须每日取用，且**取料环节是自动化的死结**：

- 青贮窖面不平整、密度不均，自动取料机容易卡刀、空切；
- 青贮在料斗、输送带上易架桥、粘附、二次发酵；
- 清洗与防霉需要人。

所以只有两条路：

| 路径 | 做法 | 代价 |
|---|---|---|
| **A. 改日粮** | 用颗粒化全价日粮/草颗粒替代青贮，干料可仓储、可流动、可自动输送 | 饲料成本可能上升，需重新做育肥配方与增重验证 |
| **B. 重投青贮自动化** | 青贮窖 + 自动取料机 + 输送 + TMR + 固定投喂线 | 12–25 万，220V 大概率不够，15 天仍有卡堵与霉变风险 |

**推荐 A。** 50 头、220V、预算受限的条件下，B 的投入产出比和可靠性都不成立。

## 三、推荐方案 V1：颗粒化全价日粮 + 固定自动饲喂线

### 3.1 日粮重构

| 原料 | 用量（kg/头·日） | 形态 | 仓储 |
|---|---|---|---|
| 肉牛育肥全价颗粒（或 TMR 颗粒） | 8–11 | 颗粒，流动 | 主料塔 |
| 草颗粒（苜蓿/羊草/秸秆） | 2–4 | 颗粒，流动 | 草料塔 |
| 矿物/添加剂 | 预混于颗粒 | — | — |

- 用**颗粒化全价日粮**替代"精料+青贮+秸秆"的湿料组合，是 15 天无人值守的前提。
- 必须由营养师按育肥前/中/后期设计配方，重点保证有效纤维，避免颗粒过细导致瘤胃酸中毒。
- 建议先做 30 天饲喂对比试验，确认日增重与料肉比可接受后再定案。

### 3.2 系统组成

```
主料塔 10 t（称重 + 料位 + 破拱）
草料塔 3 t（称重 + 料位 + 破拱）
        ↓ 计量绞龙 ×2（变频）
        ↓ 混合绞龙（可选）
        ↓ 沿槽链式输送线 35–50 m（多下料口）
        ↓ 料槽

兜底料仓 1–2 t（独立重力式，主线路故障时定时放料）
控制柜：PLC + 称重 + 4G + 触摸屏 + 摄像头接口
```

- **链式输送优于皮带**：颗粒料不易跑偏、可长距离、断带风险低，适合无人值守。
- **兜底料仓是 15 天方案的关键**：主线路任何故障超过设定时长，独立料仓按固定量放料，保证牛不挨饿。
- 下料口每 2–3 m 一个，共 15–20 个，开度可调。

### 3.3 15 天储料核算（50 头）

| 项目 | 日耗 | 15 天需求 | 仓储建议 |
|---|---|---|---|
| 全价颗粒 | 500 kg | 7.5 t | 10 t 料塔（约 15 m³） |
| 草颗粒 | 150 kg | 2.25 t | 3 t 料塔（约 5.5 m³） |
| 合计 | 650 kg | 9.75 t | 两塔合计约 20 m³ |

料塔占地约 3 m 直径 × 3.5 m 高，需硬化基础与防雨。15 天内不需要补料。

### 3.4 可靠性设计（无人值守的核心）

| 风险 | 设计对策 |
|---|---|
| 料塔结拱 | 破拱器 + 料位计 + 下料称重差值三重判断 |
| 绞龙/输送堵塞 | 电流监测 + 过载反转 + 自动重启（限次数） |
| 输送断链/跑偏 | 张紧检测 + 断链传感器 + 急停 |
| 断电 | 控制参数掉电保存，上电自动续跑；控制回路配 UPS |
| 断网 | 本地 PLC 独立执行 15 天计划，联网后补传 |
| 投喂未发生 | 料塔称重差值 + 末端传感器 + 摄像头三重验证，未投喂立即报警 |
| 主线路故障 | 兜底料仓独立放料 |
| 报警无人看 | APP → 短信 → 电话三级升级 |
| 15 天积尘/受潮 | 光滑内壁、倾斜面、快开检修口；第 15 天服务时清洁 |

**目标：15 天内零现场人工介入。** 远程监控与远程复位是否算"参与"，需明确（见第九节）。

### 3.5 软件

- 15 天投喂计划：每日 2–3 顿、按育肥阶段配方；
- 自诊断与自恢复：堵料反转、断电续跑、故障分级；
- 投喂验证：目标量 vs 实际量，未达标报警；
- 报警升级：APP → 短信 → 电话；
- 远程复位（若允许）；
- 台账：每顿时间、配方、实际量、故障；
- 多场数据模型，为合作社复制预留。

### 3.6 BOM 与功耗

| 项目 | 金额（元） |
|---|---|
| 主料塔 10 t（含称重/料位/破拱） | 10,000–18,000 |
| 草料塔 3 t | 5,000–9,000 |
| 计量绞龙 ×2 | 6,000–10,000 |
| 混合绞龙 | 3,000–6,000 |
| 链式输送线 50 m | 15,000–30,000 |
| 下料口 15–20 个 | 3,000–6,000 |
| 兜底料仓 1–2 t | 5,000–10,000 |
| 控制柜（PLC+4G+屏） | 5,000–10,000 |
| 传感器/摄像头 | 3,000–6,000 |
| 安装/土建 | 10,000–20,000 |
| **合计** | **6.5–12.5 万** |

**功耗（2026-11-10 现场确认 5 kW 容量后修订）**：输送线 1.5 kW + 计量绞龙 1.5 kW + 破拱 0.2 kW = 3.2 kW；若加混合绞龙 1.5 kW 则为 4.7 kW；饮水加热 2–3 kW 与投喂互锁，不同时运行。**系统同时运行 ≤5 kW**，220V / 32 A / 6 mm² 专线即可，不需要 63 A、不需要 380V。前提：计量绞龙主/草分时、电机错时启动（防启动电流跳闸）、加热与投喂互锁，均写入 PLC 逻辑。

### 3.7 经济性与规模建议

| 项目 | 50 头 | 100–300 头 |
|---|---|---|
| 设备投入 | 6.5–12.5 万 | 8–15 万 |
| 年折旧+能耗+维护 | 1.8–3.3 万 | 1.5–3 万 |
| 年收益（省工+减损+增重） | 1.3–2.9 万 | 3–8 万 |
| 净收益 | -0.5 ~ +1.5 万 | +1.5 ~ +5 万 |
| 回本 | 4–6 年 | 2–4 年 |

**判断：15 天无人值守在 50 头规模是"高溢价、弱经济"的产品；规模上移到 100–300 头，经济性才成立。**
建议 50 头作为验证场，产品定位与销售目标放在 100 头以上，或合作社共享。

## 四、备选 V2：青贮自动化线

- 组成：青贮窖 + 自动取料机 + 输送带 + 固定式 TMR + 固定投喂线；
- 投入 12–25 万；
- 220V 大概率不够（TMR 主电机 7.5 kW+），需 380V 增容或柴油机；
- 15 天风险：取料卡堵、青贮二次发酵、输送带粘附、清洗困难；
- **不建议**在 50 头/220V 条件下作为首版。

## 五、备选 V3：饲喂机器人

- AGV/轨道机器人 + 自动补料站 + 自动充电；
- 20–40 万，维护复杂；
- 适合 200 头以上、劳动成本高的场景；
- 首版不做。

## 六、15 天无人的范围：不只饲喂

**已确认首版范围 = 饲喂 + 自动饮水；清粪/环境放二期。** 销售边界必须写明：15 天无人期间，清粪与环境仍需另行安排，否则牛舍环境会恶化。

"无人参与"若指整栋牛舍，仅饲喂自动化不够：

| 范围 | 增量投入 | 15 天可行性 |
|---|---|---|
| 仅饲喂 | 6.5–12.5 万 | 高 |
| + 自动饮水（恒温槽+10 t 缓冲+自动补水+流量） | +1.5–2.7 万 | 高 |
| + 自动清粪（散栏刮板） | +1–3 万 | 中（土建依赖） |
| + 环境控制（风机/卷帘） | +0.5–1 万 | 中 |
| + 视频监控/远程巡查 | +0.2–0.5 万 | 高 |
| **整栋无人** | **9–18.5 万** | 需验证 |

另外，15 天无人**看不到牛的健康状况**是硬伤。首版至少配摄像头 + 远程巡查；AI 疾病预警二期再做。

## 七、验证计划：3 → 7 → 15 天

不要一上来就挑战 15 天，分三级：

| 阶段 | 时长 | 目标 |
|---|---|---|
| P1 | 连续 3 天无人 | 验证投喂计划、断网续跑、报警 |
| P2 | 连续 7 天无人 | 验证料塔下料稳定性、输送线、兜底料仓 |
| P3 | 连续 15 天无人 | 验证全周期可靠性、牛只采食与增重 |

**指标：**
- 漏投次数 = 0；
- 现场人工介入次数 = 0（远程复位单独记录）；
- 投喂精度 ±2%；
- 故障自恢复率 ≥90%；
- 牛只采食量、日增重与人工组对照；
- 饮水、清粪、环境（若纳入范围）无异常。

**每次人工介入都要记录原因**，这是下一轮设计改进的输入。

## 八、风险清单

| 风险 | 等级 | 对策 |
|---|---|---|
| 日粮改变导致增重下降/成本上升 | 高 | 先做 30 天饲喂对比试验 |
| 颗粒质量不稳、结拱 | 高 | 供应商标准、破拱、料位与称重三重检测 |
| 15 天积尘/受潮/鼠害 | 中 | 封闭料塔、光滑内壁、定期服务 |
| 断电 | 高 | 控制 UPS、上电续跑；评估发电机 |
| 断网 | 中 | 本地自治，联网补传 |
| 兜底料仓失效 | 高 | 独立供电/机械定时，定期测试 |
| 牛只健康无人观察 | 高 | 摄像头 + 远程巡查，AI 二期 |
| 单场经济性弱 | 高 | 目标规模上移 100–300 头或合作社共享 |
| 售后半径 | 高 | 合作社服务节点、远程诊断优先 |

## 九、决策记录

**已定：**
1. 日粮：改颗粒化全价日粮，去掉青贮。
2. 范围：饲喂 + 自动饮水；清粪/环境二期。
3. 规模：50 头验证场，产品按 100–300 头设计。
4. 远程监控与远程复位：允许；"无人"指无现场人工，远程值班纳入系统。
5. 预算上限：**20 万元**（50 头验证场，一次性设备与安装投入）。
6. 营养师配方与日粮成本、远程运维 SLA/收费模式：**暂不考虑**，不纳入本期决策与设计约束。
7. 现场条件（2026-11-10 确认）：220V 可带 5 kW 设备；料塔基础可按设计施工、空间足够；输送线"一"字形横向布置；水源可靠（10 t 缓冲 + 自动补水，不配 40 t）；4G 稳定。

**预算含义（2026-11-10 确认，现场勘查后更新）：**

- V1 估算 7.5–15.2 万，20 万上限留有约 5–12.5 万余量；
- 现场条件确认后，原可靠性包中的大额项（40 t 储水、63 A 进线、380V）全部取消，余量转向：UPS/发电机（1.2–2.5 万）、关键备件（0.5–1 万）、双 4G 冗余、土建超支预备；
- 若余量仍充足，可把二期中的自动清粪（+1–3 万）或环境控制（+0.5–1 万）提前到首版，但需另做设计，不默认包含。
