> **v0.2（2026-11-17）卸料改 A 方案**：箱后 400 做落料槽，x=-50 全宽后门（780×180）计量；400 宽带在箱底水平接料，再 33° 抬升；取消侧壁门，解决 -Z 侧死区。

## 一、规模与装量

| 项目 | 10 头 | 说明 |
|---|---|---|
| 粗料 | 4.5 kg/头·日 → **45 kg/日** | 与 P50 同一口径 |
| 精料 | 5.5 kg/头·日 → **55 kg/日** | 2 顿/日 |
| 粗料箱 | 1.285×0.78×0.90 = 0.90 m³；**有效 0.62 m³** | 后 400 为落料槽；120 kg/m³ 时 74 kg，约 1.6 日 |
| 精料仓 | 0.385×0.50×0.60 = **0.116 m³** | 800 kg/m³ 时 92 kg，约 1.7 日 |
| 装料频次 | **1–2 日/次** | 原型按 2 日装，留 30% 余量 |

粗料容量 **56–93 kg**（有效 0.62 m³ × 容重 90–150）；样机仍需实测 5 cm 秸秆容重。

## 二、主要尺寸（P10 vs P50）

| 项目 | P10 | P50 |
|---|---|---|
| 外形（长×宽×高） | **1850×950×1640** | 2710×1110×1990 |
| 箱体 | 1285×780×900 | 2000×950×1100 |
| 精料仓 | 385×500×600 | 600×600×720 |
| 整备 / 满载 | **340 / 506 kg** | 653 / 1143 kg |
| 轴距 / 轮距 | 1200 / 760 | 1640 / 940 |
| 车架 | 1670×560×120 | 2500×700×160 |
| 轮胎 | 4×**350×130** 实心 | 4×440×170 |
| 电池 | **48V 30Ah**（1.44 kWh） | 48V 100Ah（4.8 kWh） |
| 行走 | 2×**0.4 kW**，0.5 m/s | 2×0.8 kW，0.6 m/s |
| 链板 / 侧带 / 绞龙 | 0.37 / **0.37** / 0.18 kW | 0.75 / 0.55 / 0.37 kW |
| 侧带 | **400×1555**，水平 820 + **33°** | 500×855，23° |
| 全宽后门 | **780×180**，开度 30–80 | 500×200，40–100 |
| 绞龙 | Φ90，出口 z=1050 | Φ125，出口 z=1320 |
| 轴荷（空/满） | **176/164；234/272** | 344/309；495/588（最大 521/622） |

几何关系（A 方案）：**链板 → 全宽后门 → 落料槽 → 箱底接料带 → 33° 抬升 → 槽沿**。P10：箱底 480、链板面 565、门洞 530–710（780 全宽）、落料槽 400×780、带面 425、带尾 z=-390、带端 z=1050/y=820、试验槽沿 600、料面 430；门口到带面落差 **105**，带端越槽内沿 100。链板只沿 -X 推料，门横跨全宽，**没有 -Z 侧死区**。

门后 400 为落料槽，槽底就是带面；门板下缘 30–80 定切片，2 根 24V 推杆同步。带在箱底水平段 820 全宽接料，到 z=430 后 33° 抬升；带速 ≥3× 门出料速度。

## 三、底盘与轴荷

- 车架 1670×560，40×60×3 方管；电池 500×500×200 居中偏后，离地 100。
- 轮 350×130，轮距 760，轮胎内缘 315，车架边 280，间隙 35；轮顶 350，箱底 480，间隙 130。
- 空车重心 x≈+22；满载重心 x≈-45（以两轴中点为原点，+X 为车头）。
- 轴荷：空 176/164；满载 74+92 时 **234/272**；设计上限 600 kg 时 280/320。350 胎额定 ≥400 kg/轮，余量足够。
- 三轮/四轮？**四轮、后两轮驱动**；前轮从动，差速转向，电磁失电制动。

## 五、验证范围

**做：**
1. 7.5 m 直线试验槽（10 位×0.75 m），远程驾驶 + 4 路视频；
2. 装料对接（V 型导引 + 轮挡 + 1.4 m 装料架）；
3. 同一停靠点**先粗后精**：粗 2.2 kg + 精 2.7 kg/头·次；
4. 全宽门/落料槽抗堵塞、箱底带全宽接料、链板清底；
5. 断链 2 s 停车、充电对接（4 芯）、远程复位。

**不做（留给 P50 产品）：** 15 天无人、AI 视觉、2 m 通道 90° 转弯、真实牛舍土建。

**验收指标：**
- 投料精度 ±5%/站（2–5 kg），3×150 kg + 3×50 kg 称重；
- 10 头一趟 ≤8 min；卡料 0 次/100 趟；断链停车 <2 s；
- 远程操作成功率 ≥98%；充电对接 ≤60 s；
- 剩料 <5%，10 头采食均匀。

## 六、与 P50 的继承关系

- **同构**：链板活底 → 全宽后门 → 落料槽 → 箱底接料带 → 料槽；3 点称重保留。
- **比例**：带宽 400/500=0.8；带长 1555/855=1.8（因箱底水平段）；门 780/500=1.56（全宽）；箱长 1285/2000=0.64（容量驱动）。
- **控制**：同一套控制器/4G/远程复位；P10 验证通过的参数（门开度、带速、清料时间）可直接放大到 P50。
- P50 的 4 张图纸仍是**产品目标**，不因 P10 作废；P10 只验证机构与流程。

## 七、待确认

1. 10 头试验棚的通道/槽实际尺寸；试验槽建议做成**槽沿 550–700 可调**。
2. 全宽门/落料槽的残留与搭桥：先做 2 m 透明试验段，实测残留 <5%。
3. 5 cm 秸秆松散容重（决定每车装量与趟数）。
4. 2–3 kg/站的称重精度：需在 P10 上验证“失重法 + 链板变频”，必要时把投料单位从“每头”改为“每 2–3 头”。
5. 装料架高度 1.4 m 与现有铲车/料斗的匹配。
6. 是否在 P10 上直接试用 P50 的 4G 相机方案（建议同款，减少二次验证）。
