## 三、三个必须先说清的事实

### 3.1 供电是 go/no-go 条件

- 固定式 3 m³ 立式 TMR 主电机 7.5–11 kW，**必须 380V 三相**。
- 50 头散户常只有 220V，增容 1–3 万元，且受电网条件限制，不一定批得下来。
- 若无 380V：选自走式电动 TMR 撒料车（220V 充电），或牵引式（需 50 马力以上拖拉机）。

**已确认：现场仅 220V 单相，固定式路线排除，选定路线 B（自走式电动 TMR 撒料车）。**

需注意 220V 侧的隐性约束：3–5 kW 充电功率对应 14–23 A 电流，普通 10 A 插座不够，须单独敷设 4 mm² 回路与 25 A 空开，并确认户内总容量。冬季低温下电池续航会下降 30–50%，充电位需防雨保温。

### 3.2 TMR 在 50 头规模不省人工，甚至增加

| 环节 | 人工饲喂 | TMR 饲喂 |
|---|---|---|
| 青贮取料 | 0.5–1 h | 0.5–1 h（未配取料机时相同） |
| 精料/秸秆称量入机 | 0.2–0.4 h | 0.3–0.5 h |
| 搅拌 | — | 0.2 h（可无人值守） |
| 投喂 | 0.3–0.5 h | 0.5–1 h（驾驶撒料车） |
| 清洗 | 0.1–0.2 h | 0.2–0.3 h |
| **合计** | **1.1–2.1 h/日** | **1.7–2.9 h/日** |

TMR 的省人效应要到 **200 头以上、上料机械化**后才显现。50 头单场，TMR 增加的是"配料"环节。

**因此价值主张只能是"饲料转化率与增重"，不能是"省人工"。**

### 3.3 "自动"的真实边界

- 搅拌：可自动定时 ✅
- 配方：可屏幕引导，但**上料仍需人工** ❌
- 撒料：**仍需人驾驶**（轨道/导航方案成本翻倍） ❌

准确说法是 **"机械化 + 数字化"**，不是"无人饲喂"。售前必须讲清，否则交付即失信。

## 四、整机路线对比

| 路线 | 形态 | 参考价格 | 供电 | 土建 | 适用 |
|---|---|---|---|---|---|
| A 固定式 TMR + 电动撒料车 | 3 m³ 立式 + 2 m³ 三轮 | 3.5–5.5 万 | 380V | 机房 + 地面硬化 | 有 380V、成本敏感 |
| B 自走式电动 TMR 撒料车 | 3 m³ 一体机 | 5–8 万 | 220V 充电 | 低 | 无 380V、追求一体 |
| C 牵引式 TMR + 拖拉机 | 3 m³ + 现有拖拉机 | 1.5–3 万 + 拖拉机 | — | 低 | 已有 50 马力以上拖拉机 |

**选型结论：选定 B（自走式电动 TMR 撒料车）。**
- A 需要 380V，现场不满足，排除；
- C 需 50 马力以上拖拉机，现场未确认有，暂不采用；
- B 免增容、免固定机房，代价是整机价格更高（5–8 万）、电池 3–5 年更换（0.5–1.5 万）、冬季续航衰减。

详细选型参数、数字化终端与实施计划见《02-自走式TMR选型与实施方案》。

## 五、自研控制层的重新定位

外购 TMR 已自带控制柜、称重仪表、液压/输送控制。首版若替换整机主控，风险高、保修失效、收益低。

**自研应聚焦"数据与配方层"，不做整机主控：**

| 深度 | 内容 | 单台成本 | 建议 |
|---|---|---|---|
| L1 数据层 | 读称重仪表/运行状态、配方引导屏、4G、小程序台账 | 800–1,500 元 | ✅ 首版 |
| L2 增强控制 | 启停/报警联动、后装料位/电量传感器 | 3,000–5,000 元 | 二期 |
| L3 整机主控 | 替换 OEM 控制柜（变频 + PLC + 称重） | 1–2 万元 | ❌ 首版不做 |

控制柜自研的真正用武之地在**多机联动**（TMR + 撒料车 + 饮水 + 清粪）和**远程运维**，不是单机主控。这一点与最初"控制柜自研"的设想需要修正。

| 机房/地面硬化 | — | 5,000–15,000 | 视现场 |
| 自研数据终端 + 4G 网关 | 1 | 1,000–2,000 | 配方引导、上云 |
| 安装调试/培训 | — | 3,000–5,000 | |
| **合计** | | **3.9–7.7 万** | 不含青贮取料机 |

### 6.2 ROI 估算

| 项目 | 估算 | 说明 |
|---|---|---|
| 年饲料成本 | 40–47 万 | 50 头 × 22–25 kg/日 |
| 料肉比改善 3–5% | +1.2–2.4 万/年 | TMR 的核心收益，待验证 |
| 浪费下降 2–3% | +0.8–1.4 万/年 | 减少挑食与剩料 |
| 人工节省 | 0（甚至为负） | 见 3.2 |
| 折旧（5 年） | -0.8–1.5 万/年 | |
| 电费 + 维护 + 电池摊销 | -0.5–0.9 万/年 | |
| **净收益** | **-0.4 ~ +1.4 万/年** | 回本 4 年以上，甚至不成立 |

**结论：50 头单场 TMR 经济性弱。**
- 自用/示范可以接受，但不能作为"卖给散户"的主力卖点；
- 若要复制销售，必须靠**合作社共享**或**补贴**修复经济性。

## 七、经济性修复：合作社共享配料站

把 TMR 从"单场设备"变成"合作社级服务设备"：

| 项目 | 估算 |
|---|---|
| 设备 | 8–10 m³ TMR + 配送/撒料车，10–15 万 |
| 服务规模 | 5–10 户，200–400 头 |
| 收费 | 加工费 30–50 元/吨，或 0.5–1 元/头·日 |
| 年收入 | 8–14 万 |
| 年成本 | 折旧 2–3 万 + 人工 2–3 万 + 能耗 0.5–1 万 + 维护 0.5 万 |
| 年净利 | 2–7 万 |
| 回本 | 1.5–3 年 |

**软件在这里才真正有价值**：分户配方、投料台账、按户结算、异常追溯——这是纯硬件厂商做不了的部分，也是"软硬一体"的护城河。

## 八、30–60 天验证计划

| 指标 | 目标 |
|---|---|
| 混合均匀度 | 按厂家参数，CV ≤10% |
| 撒料均匀度 | 槽内剩料差异 <15% |
| 日粮成本 | 记录实际配方成本 |
| 采食量/日增重 | 与人工组对照，**这是经济性成立的前提** |
| 人工耗时 | 逐环节记录，验证 3.2 的判断 |
| 故障 | 堵料、液压、电池、称重异常台账 |
| 牛只应激 | 换料过渡期观察 |

**关键判断**：若料肉比改善不到 3%，单场 TMR 经济性不成立，应转向合作社共享模式或回退精料线。

## 十、待确认事项

已定：220V 单相；先单场验证 → 再合作社复制；全自动 = 15 天无人；去青贮改干料；饲喂 + 饮水；50 头验证；预算上限 20 万。
暂不考虑：营养师配方与日粮成本、远程运维 SLA 与收费模式（2026-11-10 确认）。

待确认（沿自走式 TMR 路线时的遗留项，已随重构失效，仅保留现场类）：
1. 户内 220V 总容量与充电位条件（决定能否稳定 3–5 kW 充电）。
2. 牛舍通道宽度、转弯半径、地面承载（自走式整机 1.5–2 t）。
3. 青贮窖与牛舍距离、上料方式与上料区高度。
4. 验证期是否同时服务 2–3 户邻居，以测试共享服务与收费模型。
5. 是否接受"机械化 + 数字化、非无人"的产品定位。
6. 目标售价、补贴申报。
