# C 方案：远程控制投料车详细设计（v0.3）

> 日期：2026-11-11
> v0.3 变更：**取消轨道**；改为**远程控制轮式投料车**；初期由人远程驾驶并投料；后期再考虑 AI 视觉路径规划与自动处理；**当期只实现远程控制**。
> 前提：5 cm 玉米秸秆 4–5 kg/头·日；精料 5–6 kg/头·日；50 头验证；连续 15 天无现场人工（远程操作员允许）；220V / ≤5 kW；预算 ≤20 万；自动饮水保留、**不加热**；2 m 饲喂通道；**干物质 ≥70%（含水率 ≤30%），2026-11-11 已确认**。
> 结论：远程控制版比轨道版**少土建、更灵活**，但新增**视频/链路/安全/对接**四个关键点。建议先做 10 m 模拟通道样机，验证远程驾驶、装料对接、卸料、充电、断链停车，再扩 50 m。

## 一、设计前提与运营模式

| 项目 | 约束/说明 |
|---|---|
| 物料 | 5 cm 玉米秸秆散草 + 精料（颗粒优先） |
| 日喂量 | 秸秆 4–5 kg/头·日；精料 5–6 kg/头·日 |
| 规模 | 50 头验证；产品按 100–300 头模块化 |
| 无人定义 | 连续 15 天**牛舍无现场人工**；远程操作员可在场部办公室或异地 |
| 操作模式 | 初期：人远程驾驶 + 远程控制卸料；2–3 趟/日，30–40 min/趟 |
| 路径 | 不做轨道、不做 SLAM、不做自动路径；人看视频驾驶 |
| 后期 | AI 视觉/激光路径规划、自动停靠、自动卸料；本期只预留接口 |
| 电源 | 220V，同时 ≤5 kW |
| 水 | 10 t 缓冲 + 自动补水；不加热 |
| 通道 | 净宽约 2 m；车宽 1.0 m，留约 1.0 m 人行 |
| 水分 | **已确认：干物质 ≥70%（含水率 ≤30%）**；进场每批抽测，超限拒收/单独堆放 |

**运营本质：** 不是"无人车"，是"**远程驾驶的投料车**"。15 天无人指牛舍里没人，但每天有 2–3 次远程操作；远程操作员不在现场，不违反"无人"定义。

## 二、总体布局（无轨道）

```
装料站（可移位）                    2 m 饲喂通道                    充电桩
┌──────────────┐   ┌──────────────────────────────────┐   ┌────────┐
│ 链板活底仓    │   │ 地面标线/停靠点 ×18               │   │ V 型导引│
│ 斜向输送      │   │ 投料车（轮式，远程驾驶）           │   │ 充电    │
│ 精料塔 8 t    │   │ 车宽 1.0 m，留 1.0 m 人行         │   │        │
│ 水箱 10 t     │   │                                  │   │        │
└──────────────┘   └──────────────────────────────────┘   └────────┘
```

- 地面划线/贴标出 18 个停靠点，不铺轨道；
- 装料站和充电桩设 **V 型导引/轮挡**，远程驾驶员看摄像头开进去即可，不需要精确对位；
- 车在 2 m 通道内行驶，车宽 1.0 m，留约 1.0 m 人行/检修；
- 若地面不平/有门槛，先做地面找平/硬化；这是无轨方案的前置条件。

## 三、投料车本体

### 3.1 底盘与行走

| 项目 | 建议 |
|---|---|
| 形式 | 四轮电动底盘，差速驱动/后轮驱动，橡胶实心胎 |
| 外形 | 2.6 m 长 × 1.0 m 宽 × 1.6–1.7 m 高（粗料箱加高到 1.1 m） |
| 载重 | 整车满载 ≤1.2 t |
| 行走电机 | 48V 0.75–1.5 kW，0.2–0.6 m/s，电子调速 |
| 制动 | 电磁失电制动 + 手动驻车；断电抱闸 |
| 转向 | 差速转向（原地转向）或后轮转向；转弯半径 ≤1.5 m |
| 轮胎 | 4×440×170 实心橡胶/聚氨酯，额定 ≥600 kg/轮；防滑、耐粪污；IP65 电机 |
| 轴距/轮距 | 1640 / 940 mm；车架宽 700，电池仓 600 宽（轮胎内缘 385，车架边 350，间隙 35） |
| 离地间隙 | 120（电池底）/ 300（车架底）；过门槛/粪沟盖板 |
| 编码器/IMU | 轮速编码器 + IMU，本期用于速度/里程，后期 AI 用 |

### 3.2 料箱与卸料

| 项目 | 建议 |
|---|---|
| 粗料箱 | 2.0×0.95×1.1 m，约 2.09 m³；链板活底 |
| 粗料容量 | 190–310 kg（取决于容重 90–150 kg/m³；样机必须实测；目标 250 kg 需 ≥120 kg/m³） |
| 精料仓 | 0.6×0.6×0.7 m，约 0.25 m³，**150–180 kg**；独立小仓，带 3 点称重 |
| 粗料卸料 | 链板 0.75 kW + 横向挡边皮带 0.37–0.55 kW；带宽 500 mm，箱壁至带端 0.85 m、仰角 23°；侧卸门开度可调 |
| 精料卸料 | Φ125 mm 绞龙，0.37–0.55 kW，独立下料口 z=1320；与粗料带同侧、沿车长错位 450 mm |
| 称重 | 车体 3 点（3×500 kg）+ 精料仓 3 点（3×100 kg），分别计量 |
| 清洁 | 链板空转清底；侧板快开；底部清空门；精料绞龙每日清空/干燥 |

**为什么不用绞龙卸粗料：** 5 cm 秸秆会缠绕、压实；链板 + 挡边皮带是粗饲料的常规组合。

**粗料卸料路径（侧卸门 → 横向挡边皮带 → 料槽）：**

1. 链板活底把粗料向车尾输送；尾部侧壁下方开 500×200 mm 侧卸门，门板由电动推杆升降，开度 40–100 mm 可调，用于粗调流量。
2. 门洞外侧接 500 mm 宽横向挡边皮带，箱壁至带端 0.85 m（有效落料伸出约 0.8 m）；因槽沿（约 0.7 m）高于箱底（约 0.52 m），皮带需上仰约 23° 才能越过槽沿。皮带尾端置于门洞下方（距箱壁 85 mm），门板与皮带不干涉，门框与带尾之间用柔性导料裙密封；皮带两侧挡边 50 mm、横隔板 70 mm，带速 0.3–0.5 m/s。
3. 皮带端部越过料槽内沿 0.10–0.15 m，草料从端部唇板落入槽内，落差 0.2–0.35 m；槽内料面低于槽沿约 150 mm，避免牛只拱出。
4. 每站先开链板 + 侧带；车体 3 点称重到 10–15 kg 后关侧卸门，侧带空转 2–3 s 清料。门洞与皮带之间设柔性导料裙，端部设唇板，减少撒漏。
5. 精料绞龙下料口同样伸到料槽内沿上方，与粗料出口沿车长错开 300–400 mm；每站先粗后精。

**精料也走投料车，但不在车上混合：**

- 粗料箱和精料仓**分仓**，精料仓后置，独立绞龙下料；后置 150–180 kg 会增加后轴荷，总图阶段必须复核**轴荷/重心**，必要时精料仓前移或调整电池位置；
- 精料仓按颗粒料设计（Φ100–120 mm 绞龙）；若用粉料，绞龙放大到 Φ150 mm，并加振动/破拱，否则易结拱；
- 每个停靠点**先卸粗料、再卸精料**：粗料铺底，精料落在上面，牛先吃精料，减少拱料/挑食；
- 不设独立精料输送线，减少一套 50 m 线和下料口；换来的是一车两仓、两套卸料机构；
- **不建议车上搅拌**：5 cm 秸秆 + 精料混合需要 2–3 kW 搅拌功率，精料易沉底，清洗困难；粗精分开卸已经满足日粮要求。

### 3.3 远程控制与视频

| 项目 | 建议 |
|---|---|
| 控制链路 | 4G 工业路由器 + 场内 WiFi AP 双链路；WiFi 优先，4G 备份 |
| 视频 | 前、后、卸料侧、装料侧 4 路 1080p；H.265；红外夜视 |
| 驾驶 | 工业摇杆/手柄 + 平板/笔记本；前进/后退/转向/急停 |
| 卸料控制 | 链板启停、侧带启停、精料绞龙、单站卸料 |
| 状态回传 | 车速、电量、SOC、称重、故障、摄像头 |
| 延迟目标 | 控制 ≤200 ms；视频 ≤500 ms（4G），≤200 ms（WiFi） |
| 操作站 | 场部办公室或异地；大屏显示视频 + 仪表 + 报警 |
| 网络安全 | VPN/加密、账号权限、禁止公网直连 |

**视频是远程驾驶的核心。** 至少 4 路：前视（看路/牛）、后视（倒车）、卸料侧（看料槽）、装料侧（看对接）。夜间加红外/补光灯。

### 3.4 安全与失效保护

| 风险 | 措施 |
|---|---|
| 链路中断 | 心跳丢失 >2 s 自动停车；本地声光报警 |
| 视频丢失 | 自动降速/停车；不允许盲开 |
| 障碍/牛只 | 前后超声波/红外 + 软 bumper；触发即停 |
| 人员误入 | 低速 0.2–0.6 m/s；声光提示；急停 |
| 失控 | 独立安全控制器；急停切断行走动力；手动驻车 |
| 电池异常 | BMS 过温/过流/低压保护；报警 |
| 翻车/倾斜 | IMU 倾角监测；超限停车 |
| 远程误操作 | 摇杆回中停车（deadman）；权限分级；操作日志 |

**安全控制器必须独立于主控制器**，不能只靠软件。远程驾驶可以省轨道，但不能省安全。

### 3.5 供电与充电

| 项目 | 建议 |
|---|---|
| 电池 | 48V 5–8 kWh LiFePO4，BMS，IP65 |
| 续航 | 2–3 趟/日；按 2.5–3.5 kWh/日，5 kWh 够 1.5–2 天，8 kWh 更稳 |
| 充电桩 | 单桩，V 型导引 + 弹簧接触；双 1.5 kW 模块 + 双接触组 |
| 对接 | 远程驾驶员看摄像头开进 V 型导引，轮挡到位，接触自动接通 |
| 备用 | 东端/装料站 220V 防水插座 + 便携充电器；手动充电口 |
| 监测 | SOC、电压、电流、温度；低电量强制回充；充电失败报警 |

**无轨方案不做自动插枪**：靠 V 型导引 + 弹簧接触，驾驶员开进去即可；这比机械臂简单可靠。

### 3.6 AI 预留（本期不做）

- 轮速编码器 + IMU + 前视摄像头已装；
- 预留 **CAN/Ethernet**、**工业计算机/ Jetson 安装位**、**深度相机/激光雷达支架**；
- 预留 **电子油门/转向/制动** 接口（drive-by-wire）；
- 后期加：视觉/激光 SLAM、路径规划、自动停靠、自动卸料、障碍绕行；
- 本期软件只做远程控制 + 安全 + 称重 + 台账，不做自主导航。

## 四、装料站与装料详细方案（无轨对接）

> 目标：远程驾驶员**一个人、不下车**，10–14 min 内完成 **250 kg 粗料 + 150 kg 精料**装车；称重 ±2%；撒漏 ≤0.5%；**装料时车不能动**。

### 4.1 布置原则：端部死端装料，车头进、车尾退

2 m 通道内不做 90° 转弯。装料站放在通道**端部**，车沿通道直进，V 型导引纠偏，前保险杠顶轮挡；装完挂倒挡、看后视摄像头直退。场地允许时改成**贯通式**（前门进、后门出）更好，但 50 头改造优先用死端，土建最少。

精料塔放在装料位**侧后方**，用软管/摆臂溜槽对准车尾精料仓；溜槽必须能摆开/收回，**收回限位与车行走互锁**，车动前未收回不允许起步。

```
平面：
                    堆料场/链板仓
              ┌──────────────────────┐
              │ 6–8 m × 2.5–3 m       │
              │ 链板活底仓，出料 500×500│
              └──────────┬───────────┘
                         │ 斜向输送 4 m / 25°
                  ┌──────▼──────┐
                  │ 分料溜槽/小车 │ 1.8 m 往复
                  └──────┬──────┘
       ┌─────────────────▼─────────────────┐
       │ 装料位：V 型导引 + 轮挡 + 装料罩   │

```

### 4.4 装料流程（远程，单人）

| 步 | 时间 | 动作 | 互锁/确认 |
|---|---|---|---|
| 0 | 0:00 | 远程驾驶员从充电桩发车，沿 2 m 通道驶向装料站，进 V 口速度 ≤0.3 m/s | 前视 + 装料侧摄像头 |
| 1 | 0:00–0:01 | V 型导引纠偏，前保险杠顶轮挡；停车、驻车制动 | HMI 显示“到位”；横向 ±50 mm |
| 2 | 0:01 | 轮挡 4 芯触点接通，车进入“装料模式” | **行走使能切断**；未接通不能启动装料 |
| 3 | 0:01 | 站控自检：车在位、料未满、除尘开、急停正常、光幕无人 | 任一不满足禁止启动 |
| 4 | 0:01–0:05 | 链板仓低速出料 → 斜向输送 → 分料溜槽前后 2 趟 | 先快后慢；电流/跑偏监控 |
| 5 | 0:05–0:06 | 到 200 kg 转慢速，245 kg 点动，目标 250 kg；停链板，输送空转 5–10 s 清料，稳定 5 s 读数 | 粗料 250 ±2 kg |
| 6 | 0:06–0:10 | 精料塔绞龙 → 车尾精料仓，目标 150 kg；停绞龙，free-fall 补偿 1–2 kg | 精料 150 ±2 kg |
| 7 | 0:10–0:11 | 复核重量、记录；不足补料，超差记录并下趟修正 | HMI/台账 |
| 8 | 0:11–0:12 | 停除尘（延时 2 min）、分料回位、触点断开、行走使能恢复 | 后视摄像头倒出 |
| 9 | 0:12–0:13 | 清撒漏盘；每 3 天清除尘器；每周查链条/皮带张紧 | 点检表 |

**总时间 10–14 min/趟。** 2 趟/日 ≈ 20–28 min 装料；即使 2 趟/顿（容重偏低时）也只多 10–14 min。

### 4.5 称重与计量

- 车体 **3 点称重**（每点 500 kg，分辨率 0.5 kg）+ 精料仓 **3 点称重**（每点 100 kg，分辨率 0.2 kg）；装料前去皮。
- 车必须停稳、驻车制动、轮挡受力、地面水平；避免风吹和人员上下。
- **两级给料**：快进到 80%，慢进到 98%，点动到 100%；停料后输送空转清料，稳定 5 s 再读。
- **落差补偿**：粗料 3–5 kg、精料 1–2 kg，现场标定后写入 PLC。
- 精度目标：装车粗料 ±2%（±5 kg）、精料 ±2%（±3 kg）；卸料单站粗料 ±5–10%、精料 ±2–3%；整趟粗料 ±2–3%、精料 ±1–2%。
- 台账记录：车号、时间、粗料/精料重量、水分、操作员、异常。

### 4.6 装量校核（必须实测，不能先承诺 250 kg/车）

车箱几何容积 2.0×0.95×1.1 = **2.09 m³**，有效装料约 1.9–2.0 m³。5 cm 干秸秆**松散**容重 60–120 kg/m³，装实后 120–180 kg/m³：

| 容重（kg/m³） | 1.95 m³ 实装（kg） | 能否一趟 250 kg |
|---|---|---|
| 60 | 117 | 否 |
| 80 | 156 | 否 |
| 100 | 195 | 否 |
| 120 | 234 | 接近，需装实 |
| 130 | 254 | 是 |
| 150 | 293 | 是 |

**结论：** 箱高已加到 1.1 m，250 kg 仍需 **≥125–130 kg/m³** 的装实容重；到场秸秆若很松散（60–100 kg/m³），**一趟装不下 250 kg**。三个办法：

1. **装料时振动/分料摊平**：箱壁振动器或分料皮带把容重提到 125–140 kg/m³，首选，不改车；
2. **箱高再加到 1.2 m**：容积 2.28 m³，110 kg/m³ 时约 251 kg；需复核车高/重心/进出门；
3. **改 2 趟/顿**：容重 <100 kg/m³ 时，250 kg 分两车，远程驾驶员多跑一趟（多 30–40 min/日）。

**建议：** 样机第一件事实测容重；生产箱按 **1.1 m 高** 设计；在实测前，BOM/报价按“**每车 180–250 kg、必要时 2 趟/顿**”留余量。不要按 360 kg 承诺。

### 4.7 防堵、破拱、除尘

- **出料口 500×500 mm**，不用绞龙；链板仓可正转/反转/点动，靠整床物料破拱。
- 仓壁装 **0.25 kW 振动器**（可选），只在架桥时点动 5 s，不常开。
- 斜向输送 500 mm 宽、50 mm 横隔板、侧裙 100 mm；过渡段不得小于 300 mm，避免 5 cm 秸秆搭桥。
- **堵料检测**：电机电流 >110% 持续 3 s，或皮带速度 <0.2 m/s，或出料口料位无变化 → 停料、反转 3 s、再正转点动；3 次不恢复报警。
- 仓顶设 **人工耙料口**，仅在远程复位失败、人员到场时使用。
- 装料罩 + 0.75 kW 除尘器；皮带防静电、设备接地；撒漏盘 1.2×1.5 m；干秸秆粉尘属可燃粉尘，禁止明火、定期清灰。
- 进场水分 >30% 拒收/单独堆放；湿秸秆会严重架桥、霉变。

### 4.8 安全与互锁（装料时车必须“不能动”）

| 措施 | 作用 |
|---|---|
| 轮挡 4 芯弹簧触点 | 硬线 24V 许可；未到位/接触不良 → 车不能行走、站不能出料 |
| 车“装料模式” | 软件切断行走使能，只保留链板/侧带/称重 |
| 驻车制动 + 轮挡 | 双重防溜 |
| 光幕/红外 | 有人进入装料区立即停 |
| 急停 | 车、站、远程操作台三处 |
| 料满/超重 | 料位 95% 或重量 105% 停机 |
| 断链/视频丢失 | >2 s 停料、车制动 |
| 断电 | 链板/输送停，车制动；料不外溢 |
| 警示 | 装料区黄线、声光、禁止人员停留 |

## 五、投喂流程

### 5.1 每日流程（50 头，2 顿/日）

| 时间 | 动作 |
|---|---|
| 06:00 | 远程驾驶员把车开到装料站，V 型导引进位 |
| 06:01 | 轮挡触点接通，车进入装料模式（行走切断） |
| 06:02–06:14 | 装粗料 250 kg（称重到目标）→ 装精料 150 kg；总 10–14 min |
| 06:14 | 退出装料模式，远程驾驶沿通道行驶，18 个停靠点依次停靠 |
| 06:14–06:35 | 每站**先卸粗料 10–15 kg，再卸精料 5–6 kg**；看摄像头/称重 |
| 06:40 | 回充电桩，V 型导引进位，充电；清链板/侧带/精料绞龙 |
| 16:00 | 第二趟；重复 |
| 17:00 | 回桩充电；夜间待命 |

- 18 站 × 0.6–0.9 min ≈ 12–16 min，加行走 8–10 min，**20–26 min/趟**；
- 粗料按 180–300 kg 估；50 头 ×4–5 kg = 200–250 kg/顿；容重 ≥120 kg/m³ 时一趟够，<100 kg/m³ 时需 2 趟/顿；
- 精料 150–180 kg；50 头 ×5–6 kg = 250–300 kg/日，2 顿/日每顿 125–150 kg，一趟够；
- 3 顿/日则粗料 150–180 kg、精料 85–100 kg，更宽松。

### 5.2 卸料计量

- 车体 3 点称重 + 精料仓 3 点称重，停稳后读数；
- **每站先粗后精**：粗料量 = 整车重量差；精料量 = 精料仓重量差；
- 粗料 ±5–10%/站，整趟 ±2–3%；精料 ±2–3%/站，整趟 ±1–2%；
- 最后一站吃余量；偏差超限：下一站补差；连续超限报警；
- 远程驾驶员看视频 + 两套称重数字，确认卸完再走。

### 5.3 清线

- 链板 + 侧带每趟残留约 5–15 kg；
- 回站后空转清线，清空门排出；
- 残留不过夜；每 15 天服务时彻底清洗。

**开放问题：**

1. **水分口径已确认（2026-11-11）：干物质 ≥70%（含水率 ≤30%）**；下一步实测到场秸秆容重，决定箱高/趟数。

4. 装料站最终位置（端部/中段）？充电桩放装料站旁还是独立？
5. 单充电桩 + 双模块 + 备用充电口是否接受？
6. 100–300 头是单台车加长/加趟，还是两台车轮班？
7. 后期 AI 的时间表/预算？本期只预留接口。

## 十三、结论

**远程控制版可行，而且比轨道版更适合"初期人工远程、后期 AI"的路线：**

1. **取消轨道**，省土建、省定位系统，装料站/充电桩位置可调；
2. **远程驾驶**用 4G + WiFi 双链路、4 路视频、摇杆控制；断链 2 s 停车；
3. **不做自动插枪**，用 V 型导引 + 弹簧接触，驾驶员开进去即可；
4. **精料也上车**：粗料箱 + 150–180 kg 精料仓，同一停靠点先粗后精，不设独立精料线、不在车上搅拌；
5. **本期不做 AI**，只预留编码器/IMU/摄像头/CAN/算力位；
6. **先做 10 m 模拟通道样机**，验证远程驾驶、装料对接、粗精同站卸料、充电、断链停车，再扩 50 m。

**三个不能省：** 车箱链板、侧向挡边皮带、长草架兜底。**三个不能赌：** 视频链路、充电对接、远程驾驶安全。**水分口径已确认：** 干物质 ≥70%（含水率 ≤30%）。**下一个必须实测：** 5 cm 秸秆松散容重，决定每车装量/趟数；精料 150–180 kg 仓容按 50 头 2 顿/日留 15–20% 余量。
