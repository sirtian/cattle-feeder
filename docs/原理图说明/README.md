# P10-A 控制器原理图说明

本文件夹按嘉立创 EDA 的 11 个原理图分页整理说明，便于随时查阅。工程名：`P10-A 控制器载板`，原理图 `P10A-Ctrl`，PCB `P10A-PCB`。

## 一、总体架构

```
                 ┌─────────────── 24V 现场 ───────────────┐
                 │ 急停/防撞/门限位/钥匙/传感器             │
                 ▼                                        │
          S3 8×DI（光耦 24V→3.3V）                         │
                 │                                        │
 24V ─ S1 电源 ──┼── 5V ── 3V3                            │
                 │                                        │
          S2 ESP32-S3 ── I2C ── MCP23017 ── ULN2803 ── K1–K8 ── DO1–DO8（S4）
             │  │  │
             │  │  └── SPI ── ADS1256（S5，6 路称重 + 母线检测）
             │  └───── UART2 ── MAX13487 ── 5 台驱动器 RS485（S6-B）
             └──────── I2C ── SC16IS752 ── 2×UART ── BMS / 充电机 RS485（S6-A）
                        └── DS3231 RTC / TPL5010 看门狗 / SD 卡（S6-B）

安全链（不进 MCU）：急停/防撞/倾角 → 安全继电器 → 运行使能 → 主接触器 + 失电抱闸
```

## 三、网络命名约定

| 前缀/名称 | 含义 |
|---|---|
| `24V_IN / 24V_F / 24V_P` | 输入 / 保险后 / 防反接后 24V |
| `5V / 3V3` |  buck 输出 / LDO 输出 |
| `DI1–DI6` | 进 ESP32 的数字输入 |
| `MCP_DI7/8`、`MCP_P10–P17` | MCP23017 的输入/输出 |
| `DO1–DO8` | 继电器干接点输出 |
| `COIL2_1–8` | ULN2803 到继电器线圈 |
| `AIN0–3` / `AIN0_F–3_F` | ADS1256 通道 / 现场侧滤波后 |
| `BMS_A/B`、`CHG_A/B`、`DRV_A/B` | 三路 RS485 差分对 |
| `IN1–IN8` | 现场 DI 输入（端子侧） |
| `*_SENSE` | 母线分压检测 |

## 四、阅读顺序建议

1. S1 → S2：先看电源树和主控引脚；
2. S3 / S4：输入输出通道，对应现场接线；
3. S5：称重与母线检测（注意 VREF 缺基准）；
4. S6：通信与存储；
5. S7：外部连接。

## 五、已知问题与改板建议（重要）

| 位置 | 问题 | 建议 |
|---|---|---|
| S5 | **VREF 无基准源**，只有 C64/C65 滤波 | 补 2.5V 基准（REF5025/ADR4525），否则 ADS1256 无法工作 |
| S6-B | TPL5010 输出接 `RST_MCP`，不是运行使能/ESP32 EN | 按安全设计改为断开运行使能并抱闸 |
| S3 | 光耦两侧共 GND，非电气隔离 | 需要隔离时改独立 `GND_F` + 隔离电源 |
| S3 | 无每路反接/浪涌保护 | 长线/可能反接时每路加反并二极管或 TVS |
| S7 | `CHARGE_INT` 空置（引脚已 NC） | 需要充电检测时接到可用 GPIO |
| S2 | `GATE_CURR_L/R` 悬空（已 NC） | 需要时补采样电路 |
| S4 | 继电器触点容量有限 | 门推杆等感性负载外加续流/RC |
| 全板 | GND 铺铜关闭孤岛后有 13 个焊盘需手工补缝合孔 | 见 `docs/11` 第 8 节坐标清单 |
