# 10 m 远程控制投料车样机 BOM 与询价清单（v0.2）

> 日期：2026-11-11
> v0.2 变更：**取消轨道**；改为**远程控制轮式投料车**；10 m 样机改为地面划线模拟通道；新增远程控制/视频/安全；本期只做远程控制，不做 AI 路径/自动卸料。
> 前提：秸秆 4–5 kg/头·日；精料 5–6 kg/头·日；5 cm 秸秆；**干物质 ≥70%（含水率 ≤30%）——2026-11-11 已由业主确认**；2 m 通道；车宽 1.0 m；电池 + 单充电桩（双冗余模块）。
> 价格均为**预算估算**，不是报价；实际以 3 家询价为准。

## 一、样机范围

### 1.1 做什么

| 项目 | 内容 |
|---|---|
| 通道 | 平整地面划 **10 m × 2 m** 模拟通道；2 个停靠点 |
| 投料车 | 1 台远程控制轮式车，车宽 1.0 m，粗料箱 2.0×0.95×1.1 m，后置精料仓 150–180 kg |
| 远程控制 | 4G + 场内 WiFi 双链路；4 路摄像头；摇杆/平板；断链停车 |
| 装料站 | 2–3 m 试验链板仓 + 3 m 斜向输送 + V 型导引/轮挡 |
| 充电 | 单充电桩（双 1.5 kW 模块 + 双接触组）+ V 型导引 + 备用充电口 |
| 控制 | PLC + HMI + 变频 + 车体 3 点称重 + 安全 |
| 物料 | 真 5 cm 秸秆 300–500 kg + 精料 150–180 kg |

### 1.2 不做什么

- 不做轨道、不做磁条/二维码导航；
- 不做 SLAM/激光雷达/自动路径；
- 不做自动插枪/自动充电机械臂；
- 不做车上 TMR 搅拌；
- 不做 50 m 全线、18 站；
- 不做水回路（另做 1:1 小台架）。

### 1.3 样机目的

1. 验证 **2 m 通道 + 1.0 m 车宽** 远程驾驶是否可走、可停、可卸；
2. 验证 **4 路视频 + 4G/WiFi** 的延迟、盲区、夜间/粉尘表现；
3. 验证 **断链/视频丢失 2 s 停车**、bumper/超声波/急停；
4. 验证 **V 型导引装料/充电对接** 是否容忍横向 ±50 mm；
5. 验证 **5 cm 秸秆** 在车箱链板、侧带、试验仓里是否架桥/缠绕；
6. 测出真实容重、装料时间、卸料精度、残留、堵料率、耗电。

## 二、总体布置（无轨道）

```
装料站（V 型导引）              10 m × 2 m 模拟通道             充电桩（V 型导引）
┌──────────────┐   ┌──────────────────────────────────┐   ┌────────────┐
│ 2–3 m 试验仓  │   │ 地面划线；停靠点 1 → 停靠点 2     │   │ 双模块充电  │
│ 3 m 斜向输送  │   │ 车宽 1.0 m，留 1.0 m 人行         │   │ 备用充电口  │
│ 单充电桩      │   │ 远程驾驶（4G/WiFi + 4 路视频）     │   │            │
└──────────────┘   └──────────────────────────────────┘   └────────────┘
```

- 不用轨道；地面用胶带/划线/锥桶标出 10 m ×2 m；
- 2 个停靠点各放接料槽/称重箱，模拟料槽；
- 装料站和充电桩做 **V 型导引 + 轮挡**，远程驾驶员看摄像头开进去；
- 若地面不平，先局部找平/铺钢板；这是无轨样机的前提。

## 八、风险与采购注意事项

| 风险 | 对策 |
|---|---|
| 实际含水率偏高 | 按干物质 ≥70%（含水率 ≤30%）设计；进场每批测水分，>30% 拒收/单独堆放，不得进链板仓 |
| 秸秆容重偏低 | 2.09 m³ 箱在 60–120 kg/m³ 下约装 117–251 kg；样机先实测，必要时振动/平料、再加高箱体或改 2 趟/顿 |
| 远程视频/链路 | 4G + WiFi 双链路；4 路摄像头；要求供应商做断链/延迟测试 |
| 远程驾驶安全 | 独立安全控制器；bumper/超声波/急停；低速；deadman |
| 充电对接 | V 型导引 + 轮挡 + 摄像头；双模块/双接触；备用口 |
| 装料对接 | V 型入口 2.0 m→喉 1.16 m + 轮挡；横向 ±50 mm；轮挡 4 芯触点互锁 |
